# Strict-Cost SDD — 设计规范

**状态：** 提议的实验阶梯（非实现）。每一级仅在通过其门禁证据后才交付；任何一级门禁失败即中止。
**目标：** 最小化每次计划执行的美元成本。挂钟时间不受约束；token 数量仅作为成本驱动因素。
**硬性不变量：** 质量。具体而言：`sdd-quality-reviewer-catches-planted-defect` 在 **N=5 次运行**下的通过率（不是 1 次——单次运行门禁是本轮实验最薄弱的方法论）、`sdd-rejects-extra-features` 通过、所有端到端场景通过、与当前配置的盲测 A/B 交付物对等。任何质量回退即终止该级，绝无例外。

## 成本分布（2026-06-10 最终配置，go-fractals，约 $13/次运行）

| 组件 | $ | 驱动因素 |
|---|---|---|
| 控制器（会话模型，opus） | ~6-7 | ~150 轮 × 常驻上下文；提示词免疫的轮次下限（46% 思考/叙述） |
| 实现者（sonnet，10-13 次调度） | ~5-6 | 实际工作；每次约 25 轮；每次约 13 次编辑前探索调用 |
| 任务审查者（sonnet，10 个） | ~1-1.5 | 每次 3-9 轮，含包 |
| 最终审查 + 修复 | ~1 | 6 轮，含分支包 |

审查循环次数（每次运行 2-4 次）是运行间成本方差的最大来源；循环主要由实现者错误解决的计划歧义引起。

## 判断护栏（与质量共同不变量）

**降低机制成本，绝不降低判断力。** 每一级必须列举它将哪些决策移至更便宜的模型，并证明每个决策都是*机械性的*——确定性的、可脚本化的，或事后可廉价验证的。判断力保留在最高层级或由人类掌握。SDD 中的判断点明确如下：

- **BLOCKED / NEEDS_CONTEXT 处理**——诊断子代理为何卡住并选择补救措施
- **⚠️ "无法从 diff 验证"的解决**——控制器结合跨任务上下文进行裁决
- **调度策展**——歧义解决和任务边界划定（已测量为承重：Task 5 的梯度方向注释阻止了一次错误实现）
- **审查裁决和严重性校准**——什么是 Important 与 Minor
- **审查循环裁决**——判定某项发现为误报
- **升级至人类的识别**——知道计划本身是错的

任何将上述任一决策移至更便宜模型的级别必须：(a) 重构使该决策在计划阶段由昂贵模型一次性做出，(b) 添加显式升级规则在执行时将其路由回上层，或 (c) 终止。"便宜模型通常能搞对"不是验收证据——判断失败是稀有事件、高爆炸半径，且对通过/失败门禁基本不可见，这就是为什么下面每次层级变更除了 N=5 场景门禁外，还附带判断审计（对门禁运行中每个判断点进行会话恢复审讯，与昂贵控制器基线对比）。

## 论点护栏

SDD 的论点：**每个任务一个全新子代理，配以精确策展的上下文，逐任务门禁。** 下面的级别必须保留这一点。调度时任务批处理（一次实现者调度处理多个计划任务）是**反论点**——它污染了全新上下文属性并粗化了门禁——故意不在阶梯上。与论点兼容的同等调度经济性路径是计划时任务合理规模（L1）：如果计划定义了更少、规模更好的任务，SDD 仍然每个任务运行一个全新子代理。

## 阶梯（按预期 $/杠杆排序）

### L1 — 计划侧清晰度（writing-plans 变更；预计每次运行 −$1.5-3，外加方差降低）

**状态 2026-06-11（最终）：引导已端到端测试；结论重新归因。** 微测试：约束头部和 Interfaces 块确定性引导（0→5/5，0→100% 任务，精确值）；合理规模是适度的且依赖规模（svelte 规模下 9.4→8.4 任务，fractals 规模下无可移动）。完整运行：一个引导计划执行成本 $6.34/$8.49——但无引导对照组（opus 计划，完整代码）达到 $7.59/$7.73，在该范围内。**成本收益属于 opus 编写的完整代码计划；所有先前数字使用的手写散文夹具计划不具代表性，执行成本约高 2 倍。** 引导拥有的是保真度和方差：确定性约束传播（唯一一次引导运行的修复是版本下限捕获）、精确的跨任务接口、修复波次 1 对 2-4（对照组计划交付了一个真实的 Sierpinski bug，两次运行都必须修复）。writing-plans PR 主张这些理由，而非美元。草稿在 /tmp/sdd-exp/writing-plans-l1（分支 writing-plans-crisp）。

计划是每个成本的上游：任务数量决定调度次数；计划歧义决定审查循环次数；计划完整性决定实现者探索。当前 writing-plans 优化的是实现者成功率，而非执行经济性。待测试的变更：

1. **任务合理规模指导。** 今天的计划产生的任务小到"创建 .gitignore"——每个都花费一次完整调度 + 审查循环（约 $0.60-1.00 固定开销）。添加："任务是携带自身测试循环且值得一个全新审查者门禁的最小单元。将设置/配置步骤合并到需要它们的任务中；仅在审查者能有意义地拒绝的边界处拆分。" Fractals 的计划将从 10 个任务降至约 7 个。验证：调度次数下降，门禁保持，审查粒度仍能捕获植入缺陷。
2. **计划头部中的结构化 `## Global Constraints` 部分**（版本下限、命名/文案规则、平台要求）。今天这些存在于 design.md 的散文中，只有当控制器记得粘贴时才会到达审查者（一个 `go 1.26.1` 下限违规被交付是因为没人粘贴）。固定标题使其可机械提取——`task-brief` 可以自动将它们附加到每个简报（小脚本变更），完全移除一项控制器职责。
3. **每任务 `Interfaces:` 行**（消费/产出，精确签名）。控制器目前每次调度重新推导跨任务接口（其主要合法的"重述"），实现者花费约 13 次工具调用重新发现上下文。规划者已经知道接口；每任务一行将工作移至一次性完成的地方。
4. **规划者的每任务模型层级推荐**（"机械 / 标准 / 判断"）。规划者拥有控制器目前每次调度重新做出的模型选择决策的最佳信息；控制器保留覆盖权限。

验证：微测试规划者输出形状（配方风格，遵循指令设计原则），然后完整运行。注意 2026-06-10 的结果：计划*占位符*无法从当前 opus 引导——这些变更针对经济性和歧义，而非占位符卫生。

### L2 — 控制器层级（预计每次运行 −$4-5；最大的单一杠杆，门禁最严）

**状态 2026-06-11（最终）：如预注册般在门禁处死亡，但解剖有价值。** 侦察为正面（$6.68/$8.05，n=2，机制干净）。完整测试组分裂了判断面：新的 `sdd-escalates-broken-plan` 场景（显式计划自相矛盾；人类从不主动提供）在 **sonnet 下 5/5 通过**（$1.02-1.37/次运行；opus 基线 2/2）——显式冲突会被升级。但植入缺陷测试组决定性地失败：在 sonnet 控制器下，每任务质量门禁坍缩为计划合规倡导（"无断言，如要求"列在优势下），缺陷在 4/5 次运行中交付（确定性检查），只有层级固定的 opus 最终审查者曾捕获它——而同样的 sonnet 层级审查者在 opus 控制器下 5/5 标记了它。便宜控制器处理显式升级；它们吸收隐式的权威对质量裁决。一个可能的 L2b（离散规则："与计划文本冲突的审查者发现是人类的决定——升级它"）将通过保持的升级行为路由失败的判断。

**L2b 于 2026-06-11 测试（E35/E36，评估 `docs/experiments/2026-06-11-build-loop-autoresearch.md`）：改善 opus 栈，但未挽救 sonnet 级别。** 两条规则：审查者绊线（计划强制的缺陷就是发现——Important，标记为计划强制；人类决定）和控制器升级规则（计划强制的发现像任何计划矛盾一样交给人类）。在冻结的 sonnet 组合输入上微测试：0/6 → 6/6 标记发现。完整测试组：opus 控制器 2/2 内化了规则，将审查者的遗漏捕获为自描述的兜底，并升级以获得批准的修复（4241 的临时行为结构化）；升级健全性 2/2 未破。Sonnet 控制器：1/5 完整通过——转述从调度中丢弃了绊线（2/5 传递），仅传递不会实时触发它（审查者工具读取中的一次读取稀释；调度中的位置被驳斥为变量），且没有 sonnet 控制器显示兜底行为；1/5 交付了缺陷。L2b 规则是 opus 栈的候选提交。未来针对 sonnet 级别的 L2c 将配对 SKILL.md 约束配方（sonnet 逐字传递的唯一通道）与计划强制发现的强制输出格式槽（骨架在每次观察到的转述中存活，并在组合时被查阅）；未测试。原始侦察笔记如下。

**侦察（已取代）：**
Sonnet 控制器运行（claude-sonnet 编码代理）：所有门禁绿色，**$6.68 和 $8.05** / 31-41 分钟（组合带 $11.67-14.84），token 在组合带内——无便宜控制器轮次膨胀。26/26 和 31/31 次调度模型显式，比 opus 控制器显示更重（且合理）的 haiku 分层；审查循环、每任务 Important→修复→再审查、以及综合修复者规则在两次运行中均被遵循；运行 1 的控制器在再审查前捕获了修复者副作用（`go mod tidy` 移除了 cobra）——真正的裁决，而非静默吸收。但两次运行均未出现 BLOCKED/⚠️ 事件（升级点从未被压力测试），且最终审查在 sonnet 而非最强层级上运行。下面的 N=5 质量门禁 + 完整判断审计在任何技能变更前仍是强制性的。

控制器占一半美元仅仅因为它继承了会话模型。其轮次下限是提示词免疫的，所以杠杆是每轮费率——但控制器也是大多数判断点所在，所以这一级以判断优先设计：

1. **主要形式——判断前置，机制降本：** 昂贵模型在计划时做判断密集的工作（L1 的 Interfaces 行、歧义解决、每任务约束——即调度策展被预写进计划）。中层执行会话然后运行一个真正机械的循环：提取简报、调度、运行脚本、路由裁决。技能中的显式升级规则：遇到 BLOCKED、任何 ⚠️ 项、疑似误报、或计划未已回答的任何事项，便宜控制器停止并升级（给人类，或给一个全新的昂贵模型咨询调度）——它从不独自解决判断。
2. **超出标准 N=5 的门禁：** 判断审计——门禁运行中的每个 BLOCKED/⚠️/裁决事件通过会话恢复审讯，并与 opus 控制器基线处理同类事件的方式对比评分；任何静默吸收的判断调用（便宜控制器解决了本应升级的事项）无论场景裁决如何都使该级失败。
3. **用户权威保留：** 技能推荐、从不强制执行会话层级。

本轮实验的注意事项：便宜模型轮次膨胀是在多步*工作*上测量的，而非调度循环；中层控制器能否保持约 150 轮是实验要确定的部分之一。

### L3 — 审查者层级（预计每次运行 −$0.7-1；最可能在判断护栏上死亡的级别）

**状态 2026-06-11：如预注册般死亡。** 强制 haiku 任务审查者的植入缺陷 ×5：2 通过 / 1 不确定 / 2 失败（基线 5/5）；每任务 haiku 在正确严重性下干净地标记了 0/10 个植入缺陷——1 个发现但降级且理由正是被禁止的，9 个遗漏或合理化（DRY 被赞为 YAGNI；无断言测试被称为计划合规）。便宜审查者通过*倡导*缺陷而失败；通过的运行仅靠控制器冗余或最终审查存活。记录在实验日志，批次 A-E。没有结构不同的设计不要重新提议。

包审查者接近单步机械（平静时 3 轮 / 1 次 Read），这使中层下限的原始轮次膨胀理由失效——但审查彻头彻尾是判断：严重性校准、规范裁决、知道什么不该标记。机械便宜并不使决策机械。仅用完整判断测试组测试 haiku-with-package：植入缺陷 ×5、严重性校准检查（种子 Minor-vs-Important 对；校准错误使该级失败）、以及在该层级重新测量逃生舱方差。先前预期：这一级死亡，那是好结果——它将"我们怀疑便宜审查者不好"转化为记录的证据。

### L4 — 常驻上下文节食（预计每次运行 −$0.5-1）

- `task-brief --list` 模式：控制器读取任务标题 + Global Constraints，从不读完整计划（计划正文已通过简报交付）。
- 报告从 15 行缩减至 8 行。
- SKILL.md 精简（本周添加的每一节在组合配方密度下重新论证；Codex 在长会话中支付约 10k 字符 × 约 500 次重读）。

为完整性记录；每项在任何实验前需要 Jesse 的明确反转：

- **调度时任务批处理**：反论点（见护栏）。L1.1 是获准形式。

## 预算和排序

L1 和 L2.1 独立——先运行两者（约 $80：微测试 + 2×5 次运行门禁 + A/B）。L3 在 L2 确定控制器后（审查者行为取决于调度质量；约 $25——植入缺陷运行每次 $2-3）。L4 最后（便宜，但栈后重新门禁一次；约 $30）。完整阶梯含诚实 N=5 门禁总计 ≲ $150。如果每一级都通过其门禁，预期最终状态：**fractals 上 $5-7/次运行（从 $12-15）**；如果判断敏感的级别（L2 超出其主要形式、L3）如预期死亡，**$8-10/次运行**——诚实的目标，因为护栏在构造上将判断定价高于美元。
