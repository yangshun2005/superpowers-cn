# 技能设计中的说服原则

## 概述

LLM 与人类一样，会对相同的说服原则产生反应。理解这一心理机制有助于你设计更有效的技能——不是为了操控，而是为了确保关键实践即使在压力下也能被遵循。

**研究基础：** Meincke 等人（2025）以 N=28,000 次 AI 对话测试了 7 项说服原则。说服技巧使遵从率提升了一倍以上（33% → 72%，p < .001）。

## 七项原则

### 1. 权威
**是什么：** 对专业知识、资质或官方来源的遵从。

**在技能中如何运作：**
- 命令式语言："你必须"、"绝不"、"始终"
- 不可协商的表述："没有例外"
- 消除决策疲劳和合理化

**何时使用：**
- 纪律约束型技能（TDD、验证要求）
- 安全关键实践
- 公认的最佳实践

**示例：**
```markdown
✅ 先写代码后写测试？删掉。重来。没有例外。
❌ 在可行时考虑先写测试。
```

### 2. 承诺
**是什么：** 与先前行为、陈述或公开声明保持一致。

**在技能中如何运作：**
- 要求声明："声明技能使用"
- 强制明确选择："选择 A、B 或 C"
- 使用追踪：用待办事项做检查清单

**何时使用：**
- 确保技能真正被遵循
- 多步骤流程
- 问责机制

**示例：**
```markdown
✅ 当你找到一项技能时，你必须声明："我正在使用 [技能名称]"
❌ 考虑让你的搭档知道你在使用哪项技能。
```

### 3. 稀缺
**是什么：** 由时间限制或有限可用性产生的紧迫感。

**在技能中如何运作：**
- 有时限的要求："在继续之前"
- 顺序依赖："在 X 之后立即"
- 防止拖延

**何时使用：**
- 即时验证要求
- 时间敏感的工作流
- 防止"我稍后再做"

**示例：**
```markdown
✅ 完成任务后，立即请求代码审查再继续。
❌ 你可以在方便时审查代码。
```

### 4. 社会认同
**是什么：** 遵从他人所做或被视为正常的行为。

**在技能中如何运作：**
- 普遍模式："每次"、"始终"
- 失败模式："X 没有 Y = 失败"
- 建立规范

**何时使用：**
- 记录普遍实践
- 警告常见失败
- 强化标准

**示例：**
```markdown
✅ 检查清单没有待办追踪 = 步骤会被跳过。每次都是。
❌ 有些人觉得待办列表对检查清单有帮助。
```

### 5. 统一
**是什么：** 共享身份、"我们感"、群体归属。

**在技能中如何运作：**
- 协作语言："我们的代码库"、"我们是同事"
- 共同目标："我们都想要质量"

**何时使用：**
- 协作工作流
- 建立团队文化
- 非层级化实践

**示例：**
```markdown
✅ 我们是共事的同事。我需要你诚实的技术判断。
❌ 如果我错了，你或许应该告诉我。
```

### 6. 互惠
**是什么：** 回报所受恩惠的义务。

**如何运作：**
- 谨慎使用——可能让人感觉被操控
- 技能中很少需要

**何时避免：**
- 几乎总是（其他原则更有效）

### 7. 好感
**是什么：** 偏好与我们喜欢的人合作。

**如何运作：**
- **不要用于获取遵从**
- 与诚实反馈文化冲突
- 滋生谄媚

**何时避免：**
- 纪律执行中始终避免

## 按技能类型的原则组合

| 技能类型 | 使用 | 避免 |
|------------|-----|-------|
| 纪律约束型 | 权威 + 承诺 + 社会认同 | 好感、互惠 |
| 指导/技巧型 | 适度权威 + 统一 | 重度权威 |
| 协作型 | 统一 + 承诺 | 权威、好感 |
| 参考型 | 仅清晰性 | 所有说服手段 |

## 为什么有效：心理学

**明线规则减少合理化：**
- "你必须"消除决策疲劳
- 绝对化语言消除"这算例外吗？"的疑问
- 明确的反合理化对策堵住特定漏洞

**执行意图创造自动行为：**
- 清晰触发条件 + 必需动作 = 自动执行
- "当 X 时，做 Y"比"一般做 Y"更有效
- 降低遵从的认知负荷

**LLM 是类人的：**
- 在包含这些模式的人类文本上训练
- 训练数据中权威语言先于遵从行为
- 承诺序列（声明 → 行动）被频繁建模
- 社会认同模式（大家都做 X）建立规范

## 伦理使用

**正当：**
- 确保关键实践被遵循
- 创建有效的文档
- 防止可预测的失败

**不正当：**
- 为个人利益操控
- 制造虚假紧迫感
- 基于内疚的遵从

**检验标准：** 如果用户完全理解这项技巧，它是否服务于用户的真实利益？

## 研究引用

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business.
- 七项说服原则
- 影响力研究的实证基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** Call Me A Jerk: Persuading AI to Comply with Objectionable Requests. University of Pennsylvania.
- 以 N=28,000 次 LLM 对话测试 7 项原则
- 使用说服技巧后遵从率从 33% 提升至 72%
- 权威、承诺、稀缺最有效
- 验证了 LLM 行为的类人模型

## 快速参考

设计技能时，问：

1. **它是什么类型？**（纪律约束 vs. 指导 vs. 参考）
2. **我想改变什么行为？**
3. **哪些原则适用？**（纪律约束通常用权威 + 承诺）
4. **我是否组合了太多？**（不要七项全用）
5. **这合乎伦理吗？**（服务于用户的真实利益？）
