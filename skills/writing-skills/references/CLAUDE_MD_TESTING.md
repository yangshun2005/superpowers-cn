## 测试协议

对每个变体：

1. **先运行 NULL 基线**（无技能文档）
   - 记录 Agent 选择哪个选项
   - 捕获确切的合理化说辞

2. **用相同场景运行变体**
   - Agent 是否检查技能？
   - Agent 是否使用找到的技能？
   - 若违反，捕获合理化说辞

3. **压力测试**——加入时间/沉没成本/权威
   - Agent 在压力下是否仍检查？
   - 记录合规何时失效

4. **元测试**——询问 Agent 如何改进文档
   - "你有文档但没检查。为什么？"
   - "文档怎样才能更清晰？"

## 成功标准

**变体成功，如果：**
- Agent 未经提示就检查技能
- Agent 行动前完整阅读技能
- Agent 在压力下遵循技能指导
- Agent 无法合理化规避合规

**变体失败，如果：**
- Agent 即使无压力也跳过检查
- Agent 不阅读就"改编概念"
- Agent 在压力下合理化规避
- Agent 把技能当作参考而非要求

## 预期结果

**NULL：** Agent 选择最快路径，无技能意识

**变体 A：** Agent 可能在没有压力时检查，压力下跳过

**变体 B：** Agent 有时检查，容易合理化规避

**变体 C：** 强合规，但可能感觉过于僵化

**变体 D：** 平衡，但更长——Agent 会内化它吗？
