# 会话记录（session transcript）的上下文安全

一条会话记录可能超过 1 MB，或内嵌整段历史。整条打印可能撑爆执行诊断的会话上下文。所有读取会话文件的一方——控制器或子代理——每次读每个文件都必须遵守以下规则。

1. **先测量再读取。**

   ```bash
   wc -lc "$F"
   awk '{ if (length($0) > 100000) print NR, length($0) }' "$F"   # long lines
   ```

2. **绝不用 `cat` 或 `grep` 取内容。** 先取行号和计数（`grep -n … | cut -d: -f1`、`jq -r '.type' | sort | uniq -c`），再从特定行取小字段（`sed -n Np | jq -c '{…}'` 或 `| cut -c1-500`）。使用发现阶段针对当前来源确立的字段提取命令。
3. **超过 500 字符一律收窄。** 若某条记录的命令输出超过 500 字符，收紧字段或切片。
4. **只读。** 绝不修改、移动或删除会话文件。
