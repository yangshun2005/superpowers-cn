# 发现会话历史

利用当前环境中可用的工具和信息，定位你的人类伙伴所指的会话。你的知识可以提示去哪里查找；但要用实际历史来验证结果。

使用 harness 暴露的会话工具、已配置的存储、本地帮助、文档，或有边界的文件系统检查。读取文件内容前先测量文件大小，并遵循 context-safety.md。当环境指向归档或索引时，检查它们。已提供可用路径时，无需再次搜索。

用可用的会话 ID、工作目录、时间戳和匹配的对话内容确认身份。仅凭时间新近不足以确认。将所请求的会话与其子会话及无关候选区分开。当现有证据无法区分时，询问缺失的识别信息。

对每个文件系统来源，从环境中获取其完整绝对路径，展开家目录简写和变量。在案例记录和你给人类伙伴的发现答复中使用同一路径。

从观察到的记录或文档中，确定所请求调查所需的记录含义。区分人类消息与注入消息、工具结果及父代理的分派。将工具调用与其结果匹配。在计算总计前先确定用量计数器的语义。不要从另一个 harness 推断格式，也不要把缺失字段当作零。

在案例文件中记录确切来源、相关字段含义、支撑记录位置、关联会话、已排除的合理候选及未解决信息。后续读者使用该记录，而非重复发现过程。若历史缺失、无法访问或有歧义，说明具体限制，并询问缺失的路径、导出或识别细节。
