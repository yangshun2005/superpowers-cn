维度：重复工作

找出本次会话中做过不止一次的工作。

1. 将每次工具调用提取为 `(line, turn, tool, key)`，其中 `key` 为：读取/编辑/写入对应文件路径；shell 调用对应命令文本（去除行尾空白，保留完整命令）；子代理派发对应 `description` 加提示词前 80 个字符；搜索对应查询。
2. 按 `(tool, key)` 分组，报告达到或超过阈值的组：

   | 类别 | 阈值 | 豁免 |
   |---|---|---|
   | 读取、搜索 | 3 | |
   | 编辑 | 2 | |
   | shell 命令 | 2 | 状态检查和测试运行（`git status`、`ls`、`pwd`、测试运行器） |
   | 子代理派发 | 2，且 description 相同 | |
3. 对每个组，检查重复之间是否有变化（对该文件的写入、压缩、人工纠正）。说明属于哪种情况；编辑后重读不算发现，压缩后重读算发现并归因于压缩，中间无任何变化的重读本身即为发现。
4. 查找重复推导的决策：助手文本得出会话中此前已陈述过的结论（同一文件、同一设计选择、同一待运行命令）。引用两处原文。
5. 每组一条发现，附首次和末次行号及次数。
