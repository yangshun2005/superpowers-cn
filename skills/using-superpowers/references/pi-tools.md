# Pi 工具映射

技能用动作描述操作（"派发子代理"、"创建待办"、"读取文件"）。在 Pi 上，这些动作对应以下工具。

| 技能请求的动作 | Pi 对应方式 |
| --- | --- |
| 派发子代理（`Subagent (general-purpose):` 模板） | 若已安装子代理工具（如 `pi-subagents` 提供的 `subagent`），则使用它 |
| 任务跟踪（"创建待办"、"标记完成"） | 若已安装待办/任务工具，则使用它；否则在计划文件或 `TODO.md` 中跟踪任务 |

## 子代理

Pi 核心不附带标准子代理工具。`pi-subagents` 包是推荐的可选配套，提供 `subagent` 工具，支持单代理、链式、并行、异步、Fork 上下文以及恢复/状态等工作流。若没有可用的子代理工具，不要伪造 `Task` 调用；在当前会话中顺序执行，或说明未安装可选的子代理能力。

## 任务列表

Pi 核心不附带标准任务列表工具。若已安装待办/任务扩展，使用其文档中说明的工具。否则使用 Superpowers 计划文件、Markdown 清单或仓库本地的 `TODO.md` 跟踪任务。较早的 Superpowers 文档可能提到 `TodoWrite`；将其视为上述任务跟踪动作。
